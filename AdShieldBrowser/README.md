# 광고방패 (AdShield Browser)

안드로이드용 광고 차단 웹브라우저입니다. 외부 광고차단 SDK, 분석 SDK, 광고 SDK를 사용하지 않습니다.

- 알려진 광고/추적 호스트 차단
- 일부 광고 DOM 요소 숨김
- 유튜브 웹 광고 요청 차단 및 스킵 보조
- HTTPS만 허용
- WebView Safe Browsing 활성화
- 파일/콘텐츠 접근 차단
- 제3자 쿠키 차단
- SSL 인증서 오류 시 연결 중단

권한은 `android.permission.INTERNET` 하나만 사용합니다.

유튜브 공식 앱 내부 광고에는 적용되지 않으며 유튜브 웹 광고도 100% 차단을 보장할 수 없습니다.
