# Security notes

- No analytics SDK.
- No ad SDK.
- No native libraries.
- No accessibility service.
- No VPN service.
- No background service.
- No file/storage permission.
- No camera/microphone/location/contact permission.
- No JavaScript-to-Android native bridge.
- Cleartext HTTP disabled.
- SSL certificate errors are rejected.
- WebView Safe Browsing enabled.
- WebView file and content URI access disabled.
- WebView remote debugging disabled.
